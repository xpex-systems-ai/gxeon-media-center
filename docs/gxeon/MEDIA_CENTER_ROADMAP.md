# GXEON Media Center Roadmap

## Phase 0: Railway boot

Validate Docker startup, health checks, port `7000`, persistent `/app/data`, persistent `/app/logs`, authentication settings, and operational logging.

## Phase 1: Architecture shell

Publish the GXEON Media Center identity shell, document compliance and safety boundaries, preserve the protected Odysseus workspace, and define public/protected route boundaries.

## Phase 2: Operator Command Deck

Create the authenticated operator dashboard for active work, module status, alerts, approvals, and runtime health.

## Phase 3: Content Factory

Add structured workflows for briefs, drafts, editing, content packages, reuse, and human review.

## Phase 4: Avatar Studio

Add authorized avatar and voice workflows with consent tracking, asset controls, disclosure support, and review gates.

## Phase 5: Video Clipper

Add source-aware clipping, transcript handling, captions, versioning, rights notes, and approval handoff.

## Phase 6: CRM Inbox

Add customer and audience inbox workflows, lead context, response drafting, assignment, and escalation controls.

## Phase 7: Approval Queue

Add centralized human approval, reviewer comments, policy checks, evidence requirements, release decisions, and immutable audit records.

## Phase 8: Analytics and Evidence

Add performance reporting, evidence links, published-content records, experiment notes, and source/approval traceability.

## Phase 9: Integrations

Add platform integrations only after threat modeling, official API review, secret management, rate-limit handling, audit logging, and rollback plans are complete.

## Phase 10: Billing and commercial packaging

Add billing and packaging only after core safety, compliance, tenancy, support, and operational-readiness requirements are validated.
