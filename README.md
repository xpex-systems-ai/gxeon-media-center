# Surra de Pagode — Booking

Migração do site Lovable da banda para GitHub/Vercel. Código do projeto dedicado em branch isolada `surra-de-pagode-vercel` do repositório XPeX Media Center. O código original permanece no Lovable.

## Implantação

`npm install` e `npm run build`, framework TanStack Start. Configure `TICKETMASTER_API_KEY` somente no servidor para ativar a busca opcional de eventos; sem a chave, a agenda exibe fontes externas e não inventa eventos. Vídeos oficiais somente depois de confirmação dos links. A arte instrumental foi redesenhada em SVG porque a leitura de binários originais do Lovable não está disponível pela integração atual. Prévia aguardando aprovação da banda.
